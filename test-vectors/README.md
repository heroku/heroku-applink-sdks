# Shared test vectors

Inputs and expected results for the rules in the SDK spec. Every SDK's test suite runs against them. The JSON files are generated by `generate.py`. Change the generator, not the JSON files, and regenerate with:

```sh
python3 test-vectors/generate.py
```

Every file contains an object with a `cases` array. Absent values are `null`. Datetimes are RFC 3339 strings in UTC. Compare them as instants, at the precision the language's datetime type supports. A case with both `expected` and `error` passes with either result.

| File | Input | `error` |
|---|---|---|
| `invocation-context.json` | `header`, the raw `x-client-context` value or `null`. `decoded` is informational. | `invalid_inbound_data` |
| `authorization-response.json` | `body` of a `200` response | `unexpected_response`, or `unusable_authorization` with `status` |
| `attachment-resolution.json` | `env` and the `attachment` argument. `expected` has `apiUrl`, `token`, and `appId`. | `configuration` |
| `request-path.json` | `developerName`, with the expected `path` | |
